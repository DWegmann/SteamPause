# Steam Download Control 1.0.1

- SteamPause heißt jetzt **Steam Download Control**. Die portable Windows-x64-Datei heißt `SteamDownloadControl.exe`.
- Beende SteamPause vor dem Start der neuen EXE. Vorhandene Regeln und Einstellungen werden weiterverwendet. Ein aktivierter Autostart für `SteamPause.exe` wird beim ersten Start auf die neue EXE umgestellt.
- Unterstützt wird der getestete Steam-Client mit `steamclient64.dll` in Dateiversion `11.15.70.27` und passendem SHA-256-Hash.
