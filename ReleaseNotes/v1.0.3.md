# Steam Download Control 1.0.3

- Die App prüft kurz nach dem Start und danach alle zwölf Stunden auf neue Versionen. Ein Klick auf den Hinweis öffnet die Downloadseite auf GitHub.
- Im Menü des Infobereichs kannst du mit **Nach App-Updates suchen …** eine Prüfung starten. Die Titelleiste der Einstellungen zeigt die installierte Version.
